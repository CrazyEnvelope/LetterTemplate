# 💻 LetterTemplate in Python 💻  

**📅 July 2024**  

A simple **automation project** built in **Python**.  
This program takes a **letter template** and a list of names from files, then automatically generates a **personalized letter** for each person.  

---

## ✨ About the Project
- 📄 Load a **template file** with placeholders.  
- 👤 Read a list of names from an input file.  
- 📝 For each name, generate a **personalized letter**.  
- 📂 Save each letter as a separate file automatically.  

---

- **File Handling** (read & write)
